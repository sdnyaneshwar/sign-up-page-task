Overview

A React project built with Vite and Tailwind CSS, completing three tasks:





Sign-Up Page: Form with Full Name, Email, Password, and validation.



Navigation Bar: Responsive navbar with Home, About, Contact links.



UserCard Component: Displays name and email in a card layout.

Tech Stack





React, Vite, Tailwind CSS, React Router

Setup





Clone repo: git clone https://github.com/sdnyaneshwar/sign-up-page-task.git



Install: npm install



Run: npm run dev (visit http://localhost:5173)



Build: npm run build

Tasks

1. Sign-Up Page (src/pages/SignUp.jsx)





Fields: Full Name, Email, Password



Validation: Name (2+ chars), Email (valid format), Password (8+ chars)



Styling: Tailwind CSS, responsive, gradient design

2. Navigation Bar (src/components/Navbar.jsx)





Links: Home, About, Contact



Features: Mobile hamburger menu, smooth animations, glassmorphism



Styling: Tailwind CSS, gradient, responsive

3. UserCard Component (src/components/UserCard.jsx)





Props: name, email



Features: Card layout, responsive, hover effects



Styling: Tailwind CSS, shadow, rounded corners

Notes





Responsive and accessible design



Uses React Router for navigation



Optimized with Vite and Tailwind CSS
